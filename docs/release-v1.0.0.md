# One Prompt, Two Worlds · The first exhibit

Two playable responses to the same open-ended game-generation challenge:

- **LASTLIGHT — GPT-6 Astra / medium:** keep a lighthouse alive through five tides, choose upgrades, and face the Leviathan.
- **Last Light Lancer — GPT-5.6 Sol / high:** explore a debris field, recover six cores, and survive a ten-second extraction.

## Download and play

| Download | Contents |
|:--|:--|
| [Both games](https://github.com/bitofastickler/one-prompt-two-worlds/releases/download/v1.0.0/both-games.zip) | Both preserved games plus a Windows game-selection launcher |
| [LASTLIGHT](https://github.com/bitofastickler/one-prompt-two-worlds/releases/download/v1.0.0/lastlight.zip) | Astra game and its original launcher |
| [Last Light Lancer](https://github.com/bitofastickler/one-prompt-two-worlds/releases/download/v1.0.0/last-light-lancer.zip) | Sol game and its original launcher |
| [Checksums](https://github.com/bitofastickler/one-prompt-two-worlds/releases/download/v1.0.0/SHA256SUMS.txt) | SHA-256 digests for all three ZIPs |

**Extract all files**, then run `PLAY BOTH.bat` for the combined package, `PLAY LASTLIGHT.bat` for LASTLIGHT, or `run-game.bat` for Lancer. A modern desktop browser, keyboard, and mouse are all you need. No installation, external game assets, accounts, or API keys.

Both original game snapshots are preserved byte for byte. The exhibit adds illustrated covers, controls and strategy guides, a source-backed comparison, official model references, transparent methodology, and automated verification.

The model settings are owner-attributed. This is a two-build case study, not a controlled benchmark. Automated engine tests do not replace human playtesting.
