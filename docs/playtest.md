# Play both. Make your own call.

[← Back to the exhibit](../README.md)

Try the games in alternating order with the same desktop, browser, and audio setup. Record LASTLIGHT's difficulty setting. Play at least one complete attempt in each before scoring.

| Dimension | What to look for | LASTLIGHT (1–5) | Lancer (1–5) |
|:--|:--|:--:|:--:|
| First minute | Do I know my goal and controls? | | |
| Game feel | Are movement, aiming, impacts, and feedback satisfying? | | |
| Decision making | Do choices change my approach? | | |
| Coherence | Do theme, mechanics, visuals, and sound support one another? | | |
| Surprise | Does anything feel inventive or unexpected? | | |
| Pacing | Does the challenge develop without dragging or spiking unfairly? | | |
| Completion | Is success/failure clear, and does the ending feel earned? | | |
| Replay interest | Do I want another attempt? | | |

Scale: **1** actively frustrating, **2** weak, **3** functional, **4** strong, **5** memorable. These are subjective playtest ratings, not model benchmark scores. Avoid collapsing them into a universal model ranking.

Share your mode, browser, outcome, approximate play time, favorite moment, and any reproducible bug through [an issue](https://github.com/bitofastickler/one-prompt-two-worlds/issues/new/choose). Don't include personal account details or private files.
