# Last Light Lancer

A self-contained browser arcade roguelite made with plain HTML, CSS, and JavaScript.

## Play

Double-click `run-game.bat`, or open `index.html` in a browser.

## Controls

- `WASD` or arrow keys: move
- Mouse: aim
- Left click: fire
- `Space`: dash
- `E`: attune signal cores
- `1`, `2`, `3`: buy cannon, engine, and shield upgrades with scrap
- `P`: pause
- `M`: mute or unmute music
- `T`: play a short audio test tone

## Goal

Recover all six signal cores, return to the extraction ring, and hold it for ten seconds.
Crates and enemies drop scrap for upgrades. If your hull reaches zero, the run is lost.
